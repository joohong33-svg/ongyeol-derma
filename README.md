# 온결피부과 홈페이지 (시안)

미용·안티에이징 중심 피부과를 위한 원페이지 홈페이지 시안입니다.
"청결하고 세련된, 프리미엄" 느낌을 목표로 디자인했습니다.

**사이트 주소:** https://joohong33-svg.github.io/ongyeol-derma/
(GitHub Pages가 켜져 있을 때 열립니다)

> 병원명, 의료진, 주소, 전화번호 등은 모두 **가상 정보**입니다.

## 페이지 구성

| 순서 | 섹션 | 내용 |
|---|---|---|
| 1 | 히어로 | 슬로건, 상담 예약 버튼, 스크롤하면 화면 전체로 열리는 영상 |
| 2 | 약속 | 원장 직접 시술 · 피부 기록 카드 · 당일 결제 권유 없음 · 1인 1소모품 |
| 3 | 온결의 원칙 | 진료 철학 3가지 |
| 4 | 시술 안내 | 시그니처 시술 2개 + 일반 시술 4개 (이런 분께 · 시술 시간 · 회복 기간) |
| 5 | 원장 인사말 | 전체 폭 사진 위 인용문 |
| 6 | 의료진 | 원장 2명 소개 |
| 7 | 진료 과정 | 첫 방문 4단계 |
| 8 | 공간 · 장비 | 공간 사진 갤러리, 보유 장비 |
| 9 | 자주 묻는 질문 | 비용, 회복, 정품 장비 등 5문항 |
| 10 | 상담 예약 | 예약 신청 폼 (입력 검증 포함) |
| 11 | 오시는 길 | 진료 시간, 주소, 교통 · 주차 안내 |

## 디자인

- **색상:** 화이트 + 세이지 그린(`#5B7B6F`) 포인트, 웜 샌드 · 토프 · 샴페인 보조색
- **글꼴:** Noto Serif KR(제목), Pretendard(본문), Cormorant Garamond(영문 장식)
- **아이콘:** 선 굵기를 통일한 SVG (이모지 미사용)
- **반응형:** 휴대폰(360px~) · 태블릿(768px~) · PC(1024px~) 레이아웃 별도 구성
- **접근성:** 글자 대비 4.5:1 이상, 키보드 이동, 누르는 영역 44px 이상, '동작 줄이기' 설정 시 애니메이션 · 자동 재생 꺼짐

## 파일 구조

```
index.html        페이지 전체 (HTML · CSS · JavaScript 한 파일)
assets/hero.mp4   히어로 영상
```

빌드 과정이나 설치할 라이브러리가 없습니다. 글꼴은 Google Fonts와 jsDelivr에서, 사진은 Unsplash에서 불러옵니다.

## 내 컴퓨터에서 보기

`index.html`을 브라우저로 열면 됩니다. 영상까지 제대로 확인하려면 폴더에서 간단한 로컬 서버를 띄우세요 (Python 필요).

```bash
python -m http.server 5500
```

그다음 브라우저에서 http://localhost:5500 으로 접속합니다.

## 수정 후 반영하기

```bash
git add index.html assets
git commit -m "수정 내용"
git push
```

push 후 1~2분 안에 사이트에 반영됩니다.
